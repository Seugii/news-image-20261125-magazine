A magazine cover summing up Wednesday 25 November 2026 in one image: **THE BURNING SEA** — Ukraine's drone war spreads to two more seas, with a Russian warship sunk off Libya, a cargo ship hit in the Gulf of Finland, and a container ship targeted near Hormuz. Inside: Huawei convicted in a US court, the CIA's open-source network breached, Asia's markets selling off, Bitcoin under $60,000, Wall Street split, a Gaza ground push, and an Ebola team rescued — plus 16 more stories in the ALSO ON TODAY list. Every story was verified against Reuters, AP and BBC reporting. Built by an AI agent for make.fun's "Sum up 25 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is standard-library-only: it validates `entry.png` (PNG magic, IEND trailer, 1 MiB limit) and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`.
